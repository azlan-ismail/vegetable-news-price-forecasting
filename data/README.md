# Data provenance and public-release scope

## Source data

### Vegetable prices

The price source is the Department of Statistics Malaysia (DOSM) PriceCatcher
dataset:

- Catalogue: <https://open.dosm.gov.my/data-catalogue/pricecatcher>
- Licence: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Source attribution: Ministry of Domestic Trade and Department of Statistics
  Malaysia

The preprocessing script expects a joined CSV containing `date`, `item`, and
`price`. The `item` field must already have been joined from the official
PriceCatcher item lookup. The script then selects the eight manuscript
commodities explicitly, so it must not be described as reproducing the upstream
download and lookup join by itself.

The audited source extract used for this study had SHA-256:
`9cef61e206c4953681ffa4825787644c675ae6b3383dee324e3bb70029b6778a`.

### News

The news input was assembled from publisher pages discovered through Google
News. The preprocessing script expects these source columns:

`topic`, `title`, `published_date`, `publisher`, `publisher_site`,
`google_news_url`, `publisher_url`, `article_text`, and `extract_datetime`.

The audited news input had SHA-256:
`98a67031c391baadd410884bea48e944782abd9b78f9a21f6efcea03f5c637e3`.

Full article bodies, translated text, representative passages, and
headline-derived article identifiers are excluded because the repository does
not have evidence of publisher permission to redistribute them. Google News
discovery does not itself grant a redistribution licence.

## Repository files prepared for public release

### `derived/preprocessing/`

- `price_daily_causal.csv`: daily national median prices, causal forward fill,
  and sensitivity diagnostics.
- `price_features_causal.csv`: causal lag, rolling, return, and calendar
  predictors.
- `forecast_calendar_common_observed.csv`: original common-observation
  validation/test calendar used at preprocessing time.
- `forecast_item_calendar.csv`: commodity-expanded target calendar.
- `news_daily_availability.csv`: daily article-availability counts only; no
  article text.
- `preprocessing_manifest.json`: input hashes, counts, and validation checks.

### `derived/modelling/`

- `conditional_evaluation_calendar.csv`: final 30/15/45 conditional calendar.
- `conditional_split_summary.csv`: split-level counts and date ranges.
- `conditional_model_ready_dataset.csv`: shareable price predictors, aggregate
  text features, targets, and split labels.
- `conditional_text_features_by_date.csv`: aggregate text features aligned to
  eligible target dates.
- `daily_topic_sentiment_features_conditional.csv`: daily aggregate topic counts
  and sentiment values.

These included files do not contain article bodies or translations. Some files
contain prices and model targets derived from CC BY 4.0 PriceCatcher data; users
must retain DOSM attribution when redistributing adaptations.

## Inputs needed for the full notebook

The Colab notebook expects an authorized preprocessing archive containing the
price-derived files above plus the two text-bearing files generated by
`src/preprocess.py`:

- `news_primary_full_text_pretranslation.csv`
- `news_sensitivity_with_title_only_pretranslation.csv`

Those two files are intentionally absent from this repository. Place an
authorized copy in a local ZIP named
`Vegetable_Forecasting_Corrected_Preprocessing.zip`; do not commit the ZIP.
